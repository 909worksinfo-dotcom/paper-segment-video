# 流程图、鼠标引导与神经男声

本次范围仅为流程展示、注意力引导与男声自然度，保持选段、主会话粘贴、右侧面板、术语规范、原文证据和 1.2 倍速度设置

## 图示标准

按用户指定的 llm-paper-interpretation 技能的 visual-explanation 标准适配视频：小节点、蓝灰色、同层对齐、明确连接箭头和线标签，输入输出、约束与证据级别放在节点外；多阶段数据流按真实讲解顺序点亮节点并沿边移动数据点，简单关系使用静态图

图不补造未公开的参数、张量形状或失败路径，未知内容标为未给出；没有连线的模式名称表不能冒充流程图，并列模式也不能为了补齐箭头而编造固定执行顺序

鼠标使用明确的箭头形状与轻微光圈，首先指出左侧原文，随后依据旁白中的唯一锚点平滑移动到当前流程节点、要点或公式，停留时避免遮挡文字

视频本身可暂停；面板提供流程步骤回看，每步可直接定位并暂停，展示输入、输出、条件与证据标记，便于逐步检查，不需要反复拖动进度条

## 声音调研与选择

[Microsoft 官方声音表](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts) 提供中文神经男声；本次实际测试了云希和云扬，均成功返回音频，本机 Demo 采用云希男声

[edge-tts 官方项目](https://github.com/rany2/edge-tts) 支持在线合成、音色和速度设置以及时间信息，且明确限制自定义 SSML，因此本实现不宣称支持该通路无法使用的任意情绪标签或逐词表演控制

[Qwen3-TTS 官方说明](https://github.com/QwenLM/Qwen3-TTS) 提供本地可部署的中文男声和自然语言语气控制，其中 1.7B CustomVoice 支持指令控制；其代价是模型下载与本地推理资源，本机此前权重下载未成功，本次未将未完成验收的模型当成可用配音

自然度改进采用神经音色、完整场景连续合成、日常中文承接、减少模板化自问自答与长定语，避免用强行升降音高模仿自然说话；在线引擎原生 +20% 速度，不叠加 atempo 加速

普通测试句已生成真实男声音频，并获得词级时间信息；自然度不等于一个可由时长或波形验证的客观通过项，不保证听感等同真人或完全消除 AI 感

## 运行边界

在线配音仅发送旁白，PDF 与画面保留本机；原有模型解读仍使用现有 Codex 模型流程，不能把“PDF 未发给语音服务”误说成所有论文内容都从不进入模型服务

在线服务依赖网络可用性，失败最多重试三次，保留清晰错误，不自动切换声音；配置与试听文件保存在插件外的本机运行目录，不随插件分发

旧版已审核分镜可读取，未包含新流程结构时不会自动编造流程；新生成的架构场景必须给出有效节点和连线，输入输出、锚点、引用与知识覆盖均须通过校验
