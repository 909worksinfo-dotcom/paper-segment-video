# 连续 PDF、精确选区与沉稳男声

本次仅调整阅读选区与配音表达，保留主会话粘贴、右侧进度与播放器、知识复核、动态流程图、鼠标引导和原文划线

## 阅读与选择

PDF 按顺序在同一个滚动容器中展示，跳页按钮只滚动定位，不卸载其他页面；图片延迟加载，文字层持续存在，使原生选区能够越过分页间隙

默认使用自由选字，支持单字符、词语、半句、多个段落及跨页选区；保留整段点选和图表框选作为可切换入口

浏览器提交起止页、行和 UTF-16 字符偏移，后端从 PDF 原文重新计算选区和真实字形坐标，不信任浏览器提供的替代文本，不扩大到固定段落；数学补充平面字符不能被拆开，反向选区自动归一

所有选中页进入论文上下文和图像输入，每页选区坐标单独保留供视频裁切与高亮使用；单次最多连续 12 页、12000 个字符，超过时明确提示

文字层需要 PDF 包含可提取文本；纯扫描页继续使用图表框选，不宣称已经实现 OCR

## 配音表达

本机在线配置由云希切换到云扬 zh-CN-YunyangNeural，保留原生 +20% 语速，不通过强制降调制造年长声音；已开始的任务保留其声音快照，新任务使用新配置

实际声音目录将云希描述为 Lively/Sunshine，云扬描述为 Professional/Reliable；选择云扬作为更沉稳的男声起点，声音年龄感和真人感仍需听者判断

讲稿改为有经验的技术讲师口吻：句子承载单一主要意思、长短句交替、因果衔接、逻辑停顿，减少每幕自问自答及重复模板开场，不添加刻意口癖或表演标签

仍如实标注 AI 合成讲解，不声称是真人录音或名人声音复刻；Edge 接口不支持任意情感 SSML，因此没有虚构情感风格控制

## 验证

74 项 Python 测试通过，覆盖精确单字、跨页半句、反向拖选、Unicode 数学字符、空白和非法偏移拒绝，以及预览和任务创建使用同一选区；JavaScript 语法、插件结构和技能结构校验通过

实际浏览器验证：51 页连续展示，原生拖选字母 C 后只提交 C；从第 11 页末尾拖到第 12 页开头，右侧显示第 11–12 页，已建立真实生成任务 827cb74729a340ca8f0196abe55c8673，四张源图包含第 10–13 页，新声音快照为云扬；整段和框选模式回归通过

跨页原文保留选择范围内 PDF 本身的页脚数字，不冒充或添加论文内容

独立的 17.5 秒功能测试片完成实际云扬配音、两页 PDF 裁切、动态划线、鼠标引导和字幕合成，音轨与画面检测均通过，已查看两页对应截图；这是功能验证片，不作为论文知识复核通过的解读成片交付
