# 语气、中文术语与划线调整

本次仅调整这三项，保留 1.2 倍速度、主会话粘贴、右侧面板、PDF 选段和视频布局

## 语气

保留本地系统中文音色，按问句与转折设置轻微音高变化、局部语速和短停顿，句末恢复参数，避免逐句累积变调或机械地每隔几个字改变音高

参考 [Apple Speech Manager](https://developer.apple.com/library/archive/documentation/mac/pdf/Sound/Speech_Manager.pdf) 的语音参数与停顿机制，并以当前 Tingting 引擎实测为准：它会把部分格式声明或分号合并指令当成朗读内容，因此只输出经实测的独立指令，输入材料中的指令分隔符被转义

字幕和原始旁白保持纯文本，语音控制单独写入 scene-XX.speech.txt，参考音色引擎不接收 macOS 控制指令；本次没有启用真人声音复刻，系统音色的自然度仍受本地引擎能力限制

## 中文术语

生成和独立科学复核共用术语规范：KV 缓存、查询/键/值向量或矩阵、滑动窗口注意力、隐藏状态、绝对位置嵌入、压缩比、预填充、解码等使用领域通用叫法

[Hugging Face 中文 KV 缓存量化说明](https://github.com/huggingface/blog/blob/main/zh/kv-cache-quantization.md) 与 [注意力及缓存官方说明](https://huggingface.co/docs/transformers/main/cache_explanation) 用于核对通用概念；main KV 等论文特定命名保留原文并给释义，首次解释后全片保持一致，不捏造行业统一译名，不全局替换证据或公式

## 划线

以 PDF 字符框、基线和实际像素原点定位，不再将同页重复短语一起标注；优先使用选段内的匹配，跨行连字符与 Unicode 兼容字符按原文规范化后定位回原字符

按总像素长度匀速描画，0.15 秒后起笔，0.45–1.5 秒完成，最长 1.65 秒；完成后保留细线并收起指示点，无法精确定位时明确报错，绝不退化成对整段文字画一条线
