## 实测发现并处理的问题

- PDF 跨行连字符造成正确引用匹配失败：只对物理换行处的排版连字符做归一化，保留正常单词内连字符
- 短语裁切截掉原文：裁切扩展到完整文本块及公式邻域，保留完整原文行
- 任务列表每次轮询重建导致按钮节点失效：仅在列表状态变化时更新
- 旋转页面坐标与图像不一致：对内部工作副本归一化旋转，保存原始上传文件
- CED 首轮公式下标含义不清且配音遗漏小写 l 的定义：内容复核拒绝该稿，自动返修后通过
- 系统字体不包含部分 Unicode 上下标：右侧公式转成保留上下标关系的线性记法，不支持的符号回到左侧原式，不输出方框乱码
